# מקום לזרוח · Room to Shine

Сайт проекта בתאל סמית: иврит, фотографии, картины и видео.

- `app/content.ts` — ключевые тексты, ссылки и список изображений.
- `app/page.tsx` — содержание страницы.
- `app/globals.css` — оформление.
- `public/images/` — изображения.
- `public/video/` — видео для сайта (H.264/AAC).

## Разработка

Проект использует React, Vinext, Vite и серверную сборку Cloudflare Workers. Требуется Node.js версии 22.13 или новее. Выполните `npm ci`, затем `npm run dev`. Сборка: `npm run build`. Идентификатор исходного сайта исключён; для переноса нужно настроить новое окружение.

Это исходный код, не готовый статический сайт GitHub Pages. Для публикации через Pages нужна адаптация и проверка. На GitHub можно хранить код отдельно от хостинга.

Перед публикацией репозитория проверьте его видимость и права на фотографии и видео.
